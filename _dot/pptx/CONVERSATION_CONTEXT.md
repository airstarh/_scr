# Контекст работы: квиз «День города — Воронеж»

Дата: 2026-09-09

## Запрос пользователя

Создать интерактивную презентацию-квиз на тему Дня города Воронежа. Исходный текст задания и 42 вопроса находится в файле `aitxt`. Пользовательский фон презентации — `bg.png`.

Уточнения пользователя:

- стоимость вопросов: 50, 100, 150, 200, 250, 300 и 350 баллов;
- первый вопрос раздела стоит 50 баллов, каждый следующий — на 50 больше;
- в конце должен быть слайд «Спасибо за игру!»;
- допустимо использовать LibreOffice и формат ODP с последующим экспортом в PowerPoint.

## Реализованная структура

Презентация содержит 87 слайдов:

1. Титульный слайд «Квиз на тему: День города».
2. Интерактивное игровое поле: 6 разделов × 7 уровней стоимости.
3. Для каждого из 42 заданий создана пара слайдов:
   - вопрос с четырьмя вариантами и кнопкой «Показать ответ»;
   - тот же вопрос с зелёным выделением правильного ответа.
4. Последний слайд «Спасибо за игру!».

На вопросах и ответах есть возврат к игровому полю. С поля можно перейти к финалу. Использован полноэкранный фон `bg.png` и контрастные полупрозрачные панели.

## Готовые файлы

- `Квиз_День_города_Воронеж.pptx` — готовая версия PowerPoint.
- `Квиз_День_города_Воронеж.odp` — исходная версия LibreOffice Impress.
- `build_quiz_libreoffice.py` — генератор презентации через LibreOffice UNO.
- `docs/superpowers/specs/2026-09-09-voronezh-city-day-quiz-design.md` — проектная спецификация.

## Способ сборки

В окружении не был доступен обязательный загрузчик `load_workspace_dependencies` для генератора `@oai/artifact-tool`, поэтому после разрешения пользователя презентация была создана через LibreOffice 26.2 и Python UNO.

LibreOffice запускался в фоновом режиме командой:

```bash
soffice -env:UserInstallation=file:///tmp/lo_quiz_profile --headless '--accept=socket,host=127.0.0.1,port=2002;urp;StarOffice.ServiceManager' --norestore --nodefault
```

После запуска сервера генерация выполнялась из текущей директории:

```bash
python3 build_quiz_libreoffice.py
```

## Как продолжить

При следующем запросе сначала прочитать этот файл и `aitxt`. Для правок обновить данные или оформление в `build_quiz_libreoffice.py`, повторно запустить генератор и заново проверить ODP/PPTX. Не изменять посторонние файлы родительского репозитория.
