# Upstream provenance

This extension is a maintained fork of **Tree-sitter Smart Select 0.1.0** by awesometaro/taro0079.

The repository URL embedded in the published extension was empty when this fork was created. The TypeScript application sources were recovered verbatim from the published extension's source map, then maintained here under its MIT license. Package metadata, tests, build configuration, documentation, and the CommonJS Tree-sitter initialization correction are original to this fork.
